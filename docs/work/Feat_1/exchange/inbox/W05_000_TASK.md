# W05 — Evidence Contract End-to-End

Status: READY

Parent TZ: `docs/work/TZ_GRACE_ORCHESTRATOR_RUNTIME_SCOPE_CONTEXT_HARDENING.md`

## Goal

Preserve structured evidence requirements from architect plan through materializer, coder packet, verifier, reviewer, and review routing.

## Scope

- `src/grace_control/core/contracts.py`
- `src/grace_control/services/packet_materializer.py`
- `src/grace_control/services/evidence_verifier.py`
- `src/grace_control/services/reviewer_gate.py`
- `src/grace_control/services/evidence_service.py`
- `tests/`

## Required evidence fields

- `id`
- `kind`
- `stage`
- `owner`
- `producer`
- `profile`
- `required`
- `coder_blocking`
- `artifact_patterns`
- `description`
- `validation_hint`

## Tasks

1. Extend evidence model to preserve all required fields.
2. Render structured evidence in `EXECUTION_PACKET.md`, not only IDs.
3. Map legacy `pattern` to `artifact_patterns` with warning.
4. Allow string evidence only in transition mode; reject it for STRICT later.
5. Route missing evidence by owner/profile:
   - coder-owned blocking evidence → rework to coder;
   - architect-owned evidence issue → return to architect;
   - verifier-owned issue → verifier/reviewer decision.
6. Add artifact pattern checks by evidence kind.

## Acceptance

- Evidence fields survive plan → packet → verifier/reviewer.
- Missing coder-blocking evidence routes to coder rework.
- Architect-owned evidence issue does not become coder blame.
- Legacy evidence shape is visible as warning or rejected in STRICT.

## Required tests

- `test_evidence_requirement_preserves_all_fields`
- `test_materializer_renders_structured_evidence`
- `test_string_evidence_gets_warning_or_rejected_for_strict`
- `test_missing_coder_blocking_evidence_rework_to_coder`
- `test_architect_owned_evidence_issue_returns_to_architect`
- `test_artifact_patterns_replace_legacy_pattern`
