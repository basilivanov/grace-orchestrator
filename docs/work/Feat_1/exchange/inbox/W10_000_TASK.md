# Task: W10 — Remove Legacy Defaults, Duplicates, and Misleading Config

Implement the canonical wave spec:

`docs/work/Feat_1/waves/W10_REMOVE_LEGACY_DEFAULTS_DUPLICATES.md`

## Goal

Delete or disable legacy defaults and duplicate logic that keep reintroducing fail-open behavior.

## Scope

- planning/scope compiler paths
- prompt/profile definitions
- runtime/lease config
- process/command runner
- worker loop
- settings/config files
- `tests/`

## Removal targets

### Planning and scope

- Remove `PacketMaterializer.DEFAULT_SCOPE = "src/"` for executable packets.
- Remove contract fallback to `src/grace_control/`.
- Remove `pkt.setdefault("scope", [])` in executable planning path.
- Remove executable fallback plan with empty scope.
- Remove silent absolute path stripping.
- Remove silent frozen/scope overlap removal.

### Prompts/profiles

- Remove duplicate architect prompt bodies after W03.
- Delete or disable incompatible `architect-premium` or unused profiles.
- Remove active use of legacy fields `allowed_files`, `forbidden_files`, `evidence_required` once transition is over.

### Runtime, lease, process

- Remove unused lease timeout constants.
- Remove hardcoded worktree cleanup roots.
- Remove release paths without lease fencing.
- Remove generic shell execution when not explicit.
- Remove unbounded process waits.
- Remove silent cwd creation.
- Remove dead duplicate broad exception handlers.
- Replace critical swallowed exceptions with logged/observable failures.

## Acceptance

- Dangerous defaults are removed or impossible to use for executable packets.
- Duplicate config, prompt, and profile sources are deleted or disabled.
- Critical exceptions are logged and observable.
- Tests prevent reintroducing broad default scope or unfenced release paths.

## Required tests

- `test_no_default_broad_scope_constants_used_for_execution`
- `test_no_duplicate_opencode_server_url_setting`
- `test_no_selected_profile_uses_legacy_architect_schema`
- `test_critical_exceptions_are_logged_not_silently_passed`
- `test_no_release_endpoint_without_lease_fencing`

Create `docs/work/Feat_1/exchange/inbox/W10_001_SUBMISSION.md` when done.

Include exact commit SHA, changed files, test command/output, evidence for removed dangerous defaults, evidence for no selected legacy profile/schema, and known limitations.
