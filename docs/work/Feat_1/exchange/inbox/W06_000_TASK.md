# Task: W06 — Process Supervisor and Command Runner Hardening

Implement the wave specification from:

`docs/work/Feat_1/waves/W06_PROCESS_SUPERVISOR_COMMAND_RUNNER_HARDENING.md`

## Goal

Harden process execution so subprocess runs have bounded timeout behavior, preserve diagnostics, and make command runner shell behavior explicit and tested.

## Scope

- `src/grace_control/core/process_supervisor.py`
- `src/grace_control/core/command_runner.py`
- `src/grace_control/services/acceptance_pipeline.py`
- `tests/`

## Required focus

- one timeout budget for process execution;
- bounded post-stream wait;
- bounded process cleanup after timeout;
- partial stdout/stderr preserved on timeout;
- diagnostics fields: `timed_out`, `killed_pgid`, `wait_after_kill_timed_out`, `duration_ms`, command preview;
- command runner shell behavior explicit and covered by tests.

## Required tests

- `test_process_supervisor_wait_after_stream_has_timeout`
- `test_process_supervisor_kills_process_group_on_timeout`
- `test_process_supervisor_returns_partial_output_on_timeout`
- `test_command_runner_no_shell_by_default_or_explicit_shell_only`
- `test_shell_command_timeout_kills_child_process`
